1. Create a new GitHub repository (github.com/new) and upload ALL files in this folder (keep the .github folder).
2. Open the repo > Actions tab > "Build APK" > Run workflow (it also runs on every push).
3. After about 5 minutes, open the finished run and download the "HABITFLOW-apk" artifact (a zip containing app-debug.apk).
4. Copy app-debug.apk to your phone and install it (allow "Install unknown apps" when asked).
